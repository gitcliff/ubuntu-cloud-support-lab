# Mock support cases

Practise the **written** half of the job. For each case:
1. Write the ticket the way a customer would: vague, missing details, a little stressed.
2. Write your internal notes.
3. Write a first response *before* you know the answer (ask for the right data).
4. Reproduce the problem in a lab, then write the resolution response.

Use [templates/support-case.md](../templates/support-case.md).
